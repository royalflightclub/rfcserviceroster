Install RFC Service Roster

On iPhone or iPad

  1. Open this roster in Safari.
  2. Tap Share (the square with an upward arrow). Depending on your layout, open the page menu first.
  3. Scroll down and tap Add to Home Screen.
  4. If shown, turn on Open as Web App, then tap Add.
  5. Open RFC Service from your Home Screen.

If Add to Home Screen is missing, scroll to Edit Actions and add it. In current Chrome for iPhone, you can also use Share → Add to Home Screen. If unavailable there, use Safari.

In Chrome or Edge, use the install icon in the address bar or choose Install app from the browser menu. On Android, open the browser menu and choose Install app or Add to Home screen.

Open the app online once so its offline files can load. Rosters are saved separately on each device or browser. Use Export full backup and Restore backup to move existing records.
